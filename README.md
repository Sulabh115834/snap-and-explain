# Snap & Explain

1. `npm install`
2. `export FEATHERLESS_API_KEY=your_key` (Windows PowerShell: `$env:FEATHERLESS_API_KEY="your_key"`)
3. `npm start`, then open http://localhost:3000 (on a phone, use your computer's LAN IP or deploy it)

Set `MODEL` to any vision-capable model on Featherless if the default fails.
